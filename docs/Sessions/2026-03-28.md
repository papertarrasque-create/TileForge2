# Session -- 2026-03-28

## Adventure Designer Skill

Designed and implemented a Claude Code skill (`/adventure-designer`) that translates plain language into TileForge game artifacts.

### What was built

A local plugin at `~/.claude/plugins/local/tileforge-adventure-designer/` containing:

- **SKILL.md** -- Main skill with 4 operation modes:
  - **Direct Command** -- quick one-liner changes ("add a bark to the guard")
  - **Conversational Design** -- guided multi-question design for open-ended requests
  - **Blueprint** -- parses structured markdown docs with ## Quest, ## NPCs, ## Dialogue sections
  - **Modification** -- edits existing dialogues, quests, and entity properties
- **references/property-catalog.md** -- All PropertyKeys, EntityTypes, schema ranges
- **references/dialogue-format.md** -- Dialogue JSON schema, conditions, actions, examples
- **references/quest-format.md** -- Quest JSON schema, objectives, rewards, chaining
- **references/project-format.md** -- .tileforge structure, _Staging layer convention

### Key design decisions

- Git update check on invocation: scans recent commits for system file changes, skips deep read if nothing relevant changed
- Entity creation convention: sprite (0,0) placeholder, placed at (1,1) on `_Staging` layer for user to reposition
- Agent proposes IDs (snake_case quests/dialogues, PascalCase groups), user can override before writing
- Cross-reference wiring: agent understands the full dependency graph between entities, dialogues, and quests
