Which reorganization approach feels right?

Click to select

A

Tabbed Sidebar

Replace stacked panels with tabs: Map | Content | Tiles. "Content" tab holds dialogues + quests with full sidebar height. Map layers and tileset each get a dedicated tab. Simple change, keeps sidebar paradigm.

Pros

  • Minimal code change
  • Each panel gets full height
  • Familiar pattern

Cons

  • Can't see tiles + layers simultaneously
  • Sidebar width still constrains content
B

Context-Sensitive Sidebar

Sidebar shows what's relevant to current task. Painting? Show layers + tileset. Editing entity? Show properties + dialogue link. Quest work? Show quest list + objectives. Mode switches via toolbar or automatic detection.

Pros

  • Maximum space for active task
  • Reduces clutter
  • Smart UX

Cons

  • More complex state management
  • Users may not know where things went
  • Bigger refactor
C

Promote Dialogues & Quests Out of Sidebar

Dialogues and quests become full-canvas editors (like the current modal tree editor, but better). Sidebar keeps only what you need while painting: layers + tileset. Quest/dialogue editors open as full workspace views, not cramped sidebar panels.

Pros

  • Editors get full canvas space
  • Sidebar stays focused on painting
  • Room for proper quest/dialogue UX

Cons

  • Need navigation to switch modes
  • Modal editors need redesign
